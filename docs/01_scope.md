# 01_SCOPE

## System Purpose

The **Interactive Profile Engine** is a personal system designed to manage and present professional information in a dynamic and scalable way over time.

It acts as a centralized source of:
- Projects
- Experiences
- Technologies
- Certifications
- Social links

### Users & Roles

This system is designed for a single user with two interaction modes:

| User                | Interaction |
|---------------------|-------------|
| Admin (Owner)       | • Manages all content (CRUD)<br>• Updates profile information<br>• Controls visibility<br> |
| Consultant (Viewer) | • Reads and navigates the profile<br>• Consumes structured information<br>• Does not modify data |
